## SECTION C — 10 technique rules (confirm priority + wording)

Cobber uses these, in order, to decide shake vs stir vs build and the glass.
Confirm the logic reads right to you.

1. egg white → dry-shake + shake, coupe up
2. spirit + soda, no acid → build, highball (G&T)
3. herb + acid + fizz → muddle + build, highball, top soda (Mojito)
4. acid + fizz, no herb → shake base, highball, top soda (Collins, Fizz)
5. dairy + acid → shake, coupe up (cream sour)
6. dairy, no acid → build, rocks (White Russian) *[flagged ambiguous: shake-up for dessert cocktails like Brandy Alexander]*
7. acid, no fizz → shake, coupe up (Daiquiri, Whiskey Sour)
8. herb, no acid → muddle + build, rocks (Mint Julep)
9. spirit only → stir, rocks (Old Fashioned, Negroni, Manhattan)
10. default → build, rocks
