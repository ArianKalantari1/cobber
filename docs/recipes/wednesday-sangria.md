# Wednesday Sangria ($10): Spiced Cherry Wine Syrup

Status: **R&D**, for the owner's $10 Wednesday sangria. Built to order from cask red plus a
pre-batched sangria mix, so nothing is pre-mixed that might not sell. Separate from the cherry
cobbler batch (see [rescued-red-wine-cobblers.md](rescued-red-wine-cobblers.md)).
Last updated: 2026-11-08.

## 1. Spiced cherry wine syrup (makes ~1.1 L)

| Ingredient | Amount | When |
|---|---|---|
| Rescued red (taste first; no vinegar or cork) | ~450 ml | Start |
| Cask red: **Lachlan Ridge Shiraz** (dry; black cherry, spice, fine tannins) | to make 1 L with the rescued | Start |
| Morello cherries in syrup: **fruit only** (check pitted), blended | 1 jar (~680 g; ~350 g fruit) | Start |
| Frozen pitted cherries, blended (optional, for more body) | 250 g | Start |
| Oranges: peel (no pith) and juice | 2 | Start |
| Cinnamon quills, cracked | 2 | Start |
| Cloves | 4 | Start |
| Orange peel (fresh, no pith) + the **morello jar syrup** | 1 orange + ~330 ml | Off the heat: steep 30 min, lid on |
| Sugar | 1 g per ml of strained liquid, **minus the jar syrup's sugar** (~60 g; check label) | While warm, after straining |
| Citric acid (or malic 2 : citric 1) | **1.5 g to start**, up to 3 g to taste (morellos bring acid) | With the sugar |

1. Everything marked "Start" into a wide pot. Simmer uncovered ~40–50 min, stirring every
   10 min (blended fruit catches), down to about the **700 ml mark** on the pot (~800 ml with the
   frozen cherries).
2. Off the heat: add the extra orange peel and the jar syrup, lid on, steep 30 min.
3. Strain hard, pressing the pulp. Expect ~850–900 ml.
4. While warm, stir in the sugar and acid. Cool, bottle, label with the date.

- Keeps 3–4 weeks in the fridge; longer once mixed with brandy (below).
- Taste it neat: orange, cinnamon and cherry should each be intense. It is diluted ~8× in
  the glass.
- Cost ~$13 per batch with the morello jar (~$16.50 with the frozen cherries); ~1.2 L syrup.

## 2. Sangria mix (per 1 L, ~28 serves at 35 ml)

| Ingredient | Amount |
|---|---|
| Spiced cherry wine syrup | 570 ml |
| Brandy | 430 ml |
| Angostura | ~23 ml (≈1 dash per serve) |
| Orange bitters | ~23 ml (≈1 dash per serve) |

- ~16–17% alcohol: keeps for weeks in the fridge. Potassium sorbate not needed.
- More cherry: swap 5 ml of the brandy per serve for maraschino (start at 3 ml), or 10 ml
  for Guignolet/Heering (slightly weaker).

## 3. The serve

1. Wine glass: **90 ml Lachlan Ridge Shiraz** (cask, ~$4/L; Berri Dolce Rosso if a lighter, sweeter glass is wanted) + **35 ml sangria mix**.
2. Ice, then a splash of soda (~30 ml) on top.
3. Orange slice, straw. No cinnamon dust (it floats and clumps with a straw).

| | |
|---|---|
| Std drinks | ~1.45 |
| Cost | ~$1.85 |
| Pour cost at $10 | ~20% |

- If every flavour reads faint: 25 ml syrup in the mix ratio, plus a pinch more citric if too
  sweet (the Dolce Rosso is already sweet).
- Opened cask: 4–6 weeks; date the box. One 5 L Dolce Rosso ≈ 55 glasses.
